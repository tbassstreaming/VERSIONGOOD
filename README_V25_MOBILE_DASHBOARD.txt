T-BASS V25 — MOBILE DASHBOARD

Chanjman etap 6:
- Navigasyon dashboard la rete aksesib sou telefòn kòm yon ba ki glise orizontal.
- Kat estatistik yo, bouton aksyon yo, fenèt detay yo ak fòm yo adapte ak ti ekran.
- Gwosè tèks ak kontwòl yo amelyore pou manyen sou telefòn.
- Tablo yo ka glise orizontal san yo pa kraze layout la.
- Respekte anviwònman reduced motion.

Enpòtan: V25 baze sou pake V24 Rapò ak Estatistik la. Sa se yon amelyorasyon CSS/responsif; li pa ranplase tès sou plizyè telefòn oswa verifikasyon sekirite anvan deplwaman.

Kòmanse lokalman: npm install, mete varyab .env yo, epi npm start. Pa mete sekrè reyèl nan dosye piblik.
