T-BASS V22 — GESTION DES ABONNEMENTS

- Expiration automatique selon subscription_end lors du chargement des stats/clients.
- Liste actifs/expirés et ceux expirant dans les 7 jours.
- Renouvellement de 30 jours après vérification manuelle du paiement.
- Marquage manuel comme expiré et journalisation des actions.

Installation: npm install puis npm start. Configurez les variables de sécurité avant toute mise en ligne. Le système ne confirme pas lui-même les transferts NatCash/MonCash; l’admin doit vérifier le paiement.
